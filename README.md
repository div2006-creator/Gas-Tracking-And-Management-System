# Gas-Tracking-And-Management-System

A modern web-based application that allows users, admins, and delivery personnel to **book, manage, and deliver LPG cylinders efficiently**. This system solves real-world problems like delayed delivery, manual booking, and lack of tracking.

---

## 🚀 Features

### 👤 User Side

* Register & Login system
* Book LPG cylinder
* View booking status
* Dashboard with refill & safety info

---

### 🏢 Admin Side

* View all bookings
* Manage orders
* Monitor users
* Track delivery status

---

### 🚚 Delivery Side 

* Delivery personnel login
* View assigned orders
* Update delivery status (Pending → Out for Delivery → Delivered)
* Real-time order handling

---

## 🎨 UI/UX

* Modern glassmorphism design
* Responsive layout
* Clean and intuitive dashboard
* Smooth navigation

---

## 🛠️ Tech Stack
